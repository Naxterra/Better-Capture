# Editor parity direction

The Snagit Editor inspection is used as an interaction reference, not as a
source of branding or proprietary assets.

## Implemented

- Fixed File/Edit/Image/Tools/View/Help menu bar while the canvas scrolls and zooms
- Separate compact canvas-tool and contextual property strip
- Contextual color, installed-font, and font-size controls
- Editable, location-first text objects
- Selection, crop, resize, blur, cut/copy/paste
- Arrows, rectangles, ellipses, triangles, and watermarks
- Undo/redo, library access, capture history, zoom, and document dimensions

## Next parity priorities

1. Object move/resize handles and multi-object selection
2. Callouts with editable text
3. Rectangle, oval, polygon, and freehand selection modes
4. Object snapping and configurable selection tolerance
5. Fill and surrounding-content auto-fill
6. User stamps, reusable styles, and favorites
7. A recent-capture tray integrated with the editor window
